# Referencia de la API

Las funciones se importan desde `test_lib`.

## `suma(a, b)`

Devuelve la suma de dos enteros.

```python
from test_lib import suma

resultado = suma(2, 3)  # 5
```

## `resta(a, b)`

Devuelve la resta de dos enteros.

```python
from test_lib import resta

resultado = resta(5, 2)  # 3
```

## `saludar(nombre)`

Devuelve un saludo para el nombre indicado.

```python
from test_lib import saludar

mensaje = saludar("Ana")  # "Hola, Ana!"
```

## `test_function()`

Escribe un mensaje de prueba en la salida estándar.

```python
from test_lib import test_function

test_function()
```
