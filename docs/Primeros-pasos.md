# Primeros pasos

## Requisitos

- Python 3.13 o superior.

## Instalación local

Desde la raíz del repositorio:

```bash
python -m pip install .
```

## Ejemplo

```python
from test_lib import saludar, suma

print(saludar("Mundo"))  # Hola, Mundo!
print(suma(2, 3))       # 5
```

Consulta la [referencia de la API](https://github.com/sempereluismi/test-lib/wiki/Referencia-API)
para ver el resto de las funciones.
